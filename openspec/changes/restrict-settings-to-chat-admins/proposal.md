# Proposal

## Why

Сейчас любой участник группы может посмотреть, изменить и сбросить настройки бота через
`/settings`. Управление настройками чата должно быть доступно только его владельцу и
администраторам. Также требуется поднять вероятность реакции на фото по умолчанию с `0.75`
до `1`, сохранив явно заданные переопределения.

## What Changes

- **BREAKING**: все варианты `/settings`, включая просмотр и подсказку, становятся доступны
  только владельцу и администраторам текущего группового чата.
- Перед выполнением команды бот проверяет актуальную роль отправителя. Участнику без прав
  отвечает отказом; при невозможности подтвердить права команду не выполняет.
- Анонимному администратору разрешается команда от имени самой текущей супергруппы.
  Сообщение от имени другого чата или канала права не предоставляет.
- **BREAKING**: значение `photo_chance` по умолчанию становится `1` вместо `0.75`.
  Оно применяется без переопределения окружением или настройками чата, в том числе после
  `/settings reset`; `/settings` показывает новое умолчание.
- Добавляются тесты допуска, отказов и сохранения существующего поведения для администраторов.
- Устраняется устаревшее описание отсутствующей проверки прав в документации.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `chat-settings`: доступ к команде ограничивается администраторами; фиксируются поведение
  при ошибке проверки, актуальность прав и обработка сообщений от имени чата;
  вероятность реакции на фото по умолчанию повышается до `1`.

## Impact

- Основная правка: `internal/handlers/settings/settings.go`; новые тесты рядом с обработчиком.
- Дефолт задаётся в `internal/config/config.go` и через существующую сборку зависимостей
  попадает в провайдер настроек; тесты проверяют разбор конфигурации, приоритеты и сброс.
- Для обычного отправителя используется существующий Telegram Bot API `getChatMember` через
  подключённую версию telebot v3.2.1. Новые зависимости не нужны.
- Полный режим OpenSpec: появляется внешний вызов, результат которого определяет доступ,
  и меняется вероятность по умолчанию.
- Для гарантированной проверки других пользователей сам бот должен быть администратором
  чата: [ограничение Telegram](https://core.telegram.org/bots/api#getchatmember).
- Документация: раздел Settings в `AGENTS.md` и наблюдение об отсутствии авторизации в
  `openspec/specs/chat-settings/spec.md`, обе таблицы дефолтов для реакции на фото в `AGENTS.md`.

## Что не меняем

Остальные значения по умолчанию и правила валидации; хранение и кеш настроек; формат БД;
явно сохранённые значения `photo_chance` и существующее переопределение через окружение;
остальные команды и алгоритм обработки фото. Отказ в личных сообщениях сохраняется.
Настройка видимости команд в меню Telegram в эту доработку не входит.
